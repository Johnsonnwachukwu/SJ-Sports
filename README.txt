S.J SPORTS MINI STORE

HOW TO USE
1. Open index.html in a browser to preview the store.
2. To publish it online, upload index.html to a static website host (for example GitHub Pages, Netlify, or your hosting provider).
3. Product prices, names, descriptions, and image URLs are in the `products` array near the bottom of index.html.
4. Your WhatsApp number is in `WHATSAPP_NUMBER` near the bottom. It is currently set to 2347064425525. Change it if this is not the WhatsApp number where you want orders to arrive. Use country code and digits only (Nigeria example: 2348012345678; do not include + or the first 0).
5. The sample product prices and photos are placeholders. Replace them with your real products, prices, and photos before publishing.

ORDER FLOW
Customers tap “Order on WhatsApp”, select size/quantity and enter their name. The site prepares an order message including product, price, quantity and estimated item total, then opens WhatsApp. Customers still need to press Send in WhatsApp. The site does not collect payment or store customer details.

IMAGES
Product photos load from remote image URLs, so an internet connection is needed. Replace the image URLs in the products array with your own hosted product images for the best result.
